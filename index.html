GETTING STARTED

설치부터 첫 검색까지

Windows PowerShell 기준입니다. macOS와 Linux에서도 같은 Compose 구성을 사용할 수 있습니다.

  1. 01

    Agent Docs 확장 설치

    VS Code에서 확장을 설치하고 검색할 Markdown 워크스페이스를 엽니다.

    code --install-extension datanewbie-labs.markdown-agent-docs
  2. 02

    Source Graph 생성

    Agent Docs: Initialize Source Graph와 Start Graph를 실행해 아래 파일을 만듭니다.

    <workspace>/.mps/source-graph.sqlite
  3. 03

    저장소 클론과 경로 설정

    .env의 MARKDOWN_MOUNT_SOURCE를 실제 워크스페이스 경로로 변경합니다.

    git clone https://github.com/sungreong/markdown-source-graph-mcp.git
cd markdown-source-graph-mcp
Copy-Item .env.example .env
  4. 04

    Docker로 실행

    경로를 먼저 검사한 뒤 로컬 전용 MCP 서버를 시작합니다.

    python scripts/check_workspace.py "C:/path/to/workspace"
docker compose up -d --build
Invoke-RestMethod http://127.0.0.1:8811/healthz
  5. 05

    AI 클라이언트에 등록

    codex mcp add markdownSourceGraph --url http://127.0.0.1:8811/mcp
codex mcp list

WORKSPACE MODES

규모에 맞게 연결하세요

컨테이너 실행 후 임의 경로를 열지 않고, 시작할 때 허용한 범위만 검색합니다.

SINGLE

워크스페이스 하나

개인 위키나 하나의 프로젝트를 가장 간단하게 연결합니다.

MARKDOWN_MCP_MODE=single
RECOMMENDEDHUB

공통 폴더 아래 여러 개

허용된 상위 폴더 안에서 Source Graph를 찾아 root_id로 전환합니다.

MARKDOWN_MCP_MODE=hub
MULTI-ROOT

서로 떨어진 여러 경로

각 경로를 명시적으로 읽기 전용 마운트하고 고유 ID를 부여합니다.

docker-compose.multi.yml

ⓘ

이 GitHub Pages 사이트는 제품 안내 페이지입니다. 개인 Markdown 검색과 호출 이력은 외부로 전송되지 않으며, 사용자의 컴퓨터에서 실행한 로컬 대시보드에서만 제공됩니다.

서버는 Markdown을 수정하거나 삭제하는 도구를 제공하지 않습니다.
